Hostile host page

Everything on this page is styled by rules designed to wreck an embedded widget: a !important global reset, Comic Sans on every element, line-height: 3, direction: rtl, html { font-size: 28px }, content-box sizing, rules naming #chatflow-widget and iframe directly, and svg, img { display: none }.

Pass criteria

  • The launcher sits in the bottom-right corner at its normal size, unrotated, unblurred, not dashed lime.
  • Text inside the widget is Inter — not Comic Sans, not uppercase, not triple-spaced, not right-to-left.
  • The widget's icons are visible (this page hides every svg).
  • Clicking the launcher opens the panel; it fits the viewport and does not add a page scrollbar.
  • This page's own styling is unchanged with the widget installed vs. removed — the widget must not add a stylesheet, a font, or any element besides one div.
